# ElMoultaqa Landing

This is the React + Vite landing page for ElMoultaqa, a multi-tenant conference SaaS platform.

## How to run

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local URL shown in the terminal.

## Notes

- The landing page uses a clean modern SaaS design.
- Primary color is `#2563EB`.
- This project is intentionally separate from conference-specific code.
